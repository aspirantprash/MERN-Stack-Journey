# Prashant Sharma — Creative Developer Portfolio

A responsive personal portfolio built with **HTML5, CSS3, and Vanilla JavaScript**. The visual direction uses a warm cream background, bold typography, playful geometric accents, and custom CSS illustrations.

## Features

- Responsive desktop, tablet, and mobile layouts
- Accessible navigation with a mobile menu and skip link
- Project filtering (All, Useful tools, Interactive)
- Scroll reveal animations with reduced-motion support
- Current year in the footer
- Custom CSS developer illustration and project previews
- Placeholder-link feedback so unfinished URLs are easy to identify

## Run locally

1. Download or clone this folder.
2. Open `index.html` in your browser, or use the VS Code Live Server extension.
3. Edit `index.html` to replace the placeholder email, social links, GitHub repositories, and live demos.
4. Update the project descriptions/screenshots to reflect the current state of each project accurately.

## Before publishing

Search in `index.html` for:
- `YOUR_EMAIL@example.com`
- `href="#"` and `data-link=`
- `Add your college / university name here`

Replace each placeholder with real details. Do not list a technology as a mastered skill unless you can explain and use it confidently.

## Files

- `index.html` — content and structure
- `style.css` — layout, design, responsive rules, and animation
- `script.js` — mobile navigation, filters, reveal animations, and placeholder notices
