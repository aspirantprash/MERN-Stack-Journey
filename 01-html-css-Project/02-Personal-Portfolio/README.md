# 🌐 Personal Portfolio Website

A modern, responsive personal portfolio website built using **HTML5 and CSS3** to showcase my skills, projects, learning journey, and social profiles.

This portfolio is designed as a personal introduction and a place to showcase the projects I have built while learning web development.

* 🏠 Modern Content Section
* 👨‍💻 About Me Section
* 🛠️ Skills & Technologies Section
* 📂 Projects Showcase
* 📱 Responsive Design
* ✨ Hover Effects & CSS Transitions
* 🔗 GitHub, LinkedIn & Instagram Links
* 📞 Contact Section
* 🎨 Clean and modern UI
* 🖼️ External project and hero images
