# 🔢 JavaScript Counter

A simple and interactive Counter application built using **HTML, CSS, and JavaScript**.

## 🚀 Features

* ➕ Increment counter
* ➖ Decrement counter
* 🔄 Reset counter
* 🎨 Styled with CSS
* ⚡ Interactive functionality using JavaScript
* 📱 Responsive design

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript

## 📚 Concepts Practiced

* DOM Manipulation
* `querySelector()`
* Event Listeners
* Functions
* Variables
* Conditional Logic
* Updating HTML content dynamically

## 📂 Project Structure

```text
01-Counter/
├── index.html
├── style.css
├── script.js
└── README.md
```

## 🎯 Purpose

This project was created to practice JavaScript fundamentals and understand how JavaScript interacts with HTML elements through the DOM.
