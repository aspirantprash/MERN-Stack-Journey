# ⏰ Digital Clock & Date

A simple and interactive **Digital Clock & Date** web project built using **HTML, CSS, and JavaScript**.

This project displays the **current time and date** and allows users to switch between them using two buttons.

## 🚀 Features

* ⏰ Display current time
* 📅 Display current date
* 🔘 **Show Time** button
* 📆 **Show Date** button
* ⚡ Dynamic content using JavaScript
* 🎨 Clean and simple UI
* 📱 Responsive design

## 🛠️ Technologies Used

* **HTML5** – Structure of the webpage
* **CSS3** – Styling and layout
* **JavaScript** – Functionality and dynamic date/time
* **DOM Events** – Button click interactions
* **Variables** – Store and manage date/time values

## 🧠 JavaScript Concepts Practiced

This project helped me practice:

* Variables
* `Date()` object
* DOM Selection
* DOM Manipulation
* Event Listeners / DOM Events
* Updating HTML content dynamically
* Button click functionality

## ⚙️ How It Works

1. JavaScript gets the current date and time.
2. The values are stored using variables.
3. DOM elements are selected using JavaScript.
4. Clicking **Show Time** displays the current time.
5. Clicking **Show Date** displays the current date.
6. DOM events make the buttons interactive.
