# 🧮 Modern Calculator

A modern and responsive **Calculator Web App** built using **HTML, CSS, and JavaScript**.

This is my **second Calculator project**. Unlike my first calculator, this project uses a **separate JavaScript file** and focuses more on JavaScript DOM manipulation and event handling.

## ✨ Features

* ➕ Addition
* ➖ Subtraction
* ✖️ Multiplication
* ➗ Division
* 🧹 Clear (AC)
* ⌫ Delete
* 🟰 Calculate result
* ⚠️ Error handling
* 📱 Responsive modern UI

## 🛠️ Technologies

* HTML5
* CSS3
* JavaScript
* DOM Manipulation
* Event Listeners

## 📚 JavaScript Concepts

`getElementById()` • `querySelector()` • `querySelectorAll()` • `addEventListener()` • `forEach()` • `slice()` • `try...catch` • `eval()`

## 🎯 Purpose

Built to improve my **JavaScript fundamentals** and understand how JavaScript works with the **DOM**, as part of my MERN Stack learning journey.

**Previous Calculator:** HTML + CSS + Inline JavaScript
**This Calculator:** HTML + CSS + Separate JavaScript ⚡
