# 🎨 Background Color Changer

A simple and interactive **Background Color Changer** built using HTML, CSS, and JavaScript.

Click on any color card and the background color of the webpage changes instantly.  
This project was created to practice **JavaScript DOM manipulation and event handling**.

## 🚀 Features

- 🎨 Multiple color options
- 🖱️ Click-to-change background
- ⚡ Instant color change
- 📱 Simple and responsive design
- ✨ Clean and beginner-friendly UI

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
