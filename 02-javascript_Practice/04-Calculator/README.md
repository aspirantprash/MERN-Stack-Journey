# 🧮 Calculator

A simple and responsive **Calculator Web App** built using **HTML and CSS**, with JavaScript functionality through button events.

This project performs basic arithmetic operations such as **addition, subtraction, multiplication, and division**. It also includes decimal numbers, double-zero input, delete, and clear functionality.

---

## 🚀 Features

* ➕ Addition
* ➖ Subtraction
* ✖️ Multiplication
* ➗ Division
* 🔢 Decimal numbers
* 🔢 Double zero (`00`) button
* 🧹 Clear All (`AC`)
* ⌫ Delete last character (`DE`)
* 🟰 Calculate result (`=`)
* 📱 Simple and responsive layout
* 🎨 Clean calculator UI with button effects

---

## 🛠️ Technologies Used

* **HTML5** – Structure of the calculator
* **CSS3** – Styling and layout

## 🎯 Calculator Controls

| Button | Function                    |
| ------ | --------------------------- |
| `AC`   | Clears the complete display |
| `DE`   | Deletes the last character  |
| `.`    | Adds a decimal point        |
| `/`    | Division                    |
| `*`    | Multiplication              |
| `-`    | Subtraction                 |
| `+`    | Addition                    |
| `00`   | Adds two zeros              |
| `0–9`  | Adds numbers                |
| `=`    | Calculates the result       |
