# 🎓 Campusly – College Management System

**Campusly** is a modern and interactive College Management System built using HTML, CSS, and Vanilla JavaScript. It provides a user-friendly interface to manage courses, student admissions, and student records.

## ✨ Features

- **Dashboard:** College overview, total students and course statistics.
- **Course Management:** Course details, enrollment numbers, capacity and available seats.
- **Student Admission:** Add students with personal and academic information.
- **Course Selection:** Automatically select the course from the admission button.
- **Form Validation:** Required fields and duplicate roll number checking.
- **Student Records:** Store and manage student information.
- **Local Storage:** Save student and course data in the browser.
- **Login Page:** Login interface for the application.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- Browser Local Storage
- Font Awesome
